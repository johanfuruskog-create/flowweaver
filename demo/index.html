FlowWeaver

En visuell editor för beslutsguider: frågor, regler och svar, ritade som ett flöde. Guiden sparas som en fil, och visaren kör den på vilken sida som helst.

  • Bygg guiden i editorn — ändringarna sparas i den här webbläsaren.
  • Prova guiden som besökare — samma guide, som den ser ut på en sida.

Sidorna laddar de färdiga bundlarna med en vanlig script-tagg, som en värd gör. Starta demon med npm run build:lib och npm run serve:demo.
